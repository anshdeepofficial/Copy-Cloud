Frequently Asked Questions

Everything about using Copy Cloud - the fastest online clipboard for sharing text and files between devices without an account.

Is Copy Cloud free to use?

Yes. Copy Cloud is 100% free. Open the site, paste your text or drop a file, and share the 6-character code with any other device. No credit card, no trial, no ads on the send/retrieve flow.

Do I need to create an account?

No account, no email, no phone number. Copy Cloud is a true no-login clipboard - we cannot see who you are, and neither can anyone else. Your code is the only key to your clip.

How long are my files and text kept?

Everything you upload is automatically deleted after 24 hours. This makes Copy Cloud perfect for quick device-to-device transfers, but it is not a long-term storage or backup service.

Is it safe to share files this way?

All uploads travel over HTTPS and are stored behind a random 6-character code. As long as you only share the code with your intended recipient, no one else can retrieve the clip. For sensitive material, delete it manually after use.

What size of files can I transfer?

The current free tier supports files up to the limit shown on the Send tab. A Pro tier with larger caps (up to 1 GB), password protection and custom expiry is coming soon.

Which devices and browsers work?

Any modern browser: Chrome, Safari, Firefox, Edge, Brave, Samsung Internet, and more. Copy Cloud is installable as a PWA on both Android and iOS so it feels like a native app.

How does the QR code work?

Each generated code has a matching QR you can scan from any phone camera. Scanning opens Copy Cloud with the code pre-filled on the Retrieve tab, so the file downloads with one tap.

Can I use Copy Cloud for business?

Yes - freelancers, designers, developers and support teams use Copy Cloud daily to move screenshots, logs, and documents between machines. For heavy team use, wait for the upcoming Pro plan with longer expiry and password-protected clips.
