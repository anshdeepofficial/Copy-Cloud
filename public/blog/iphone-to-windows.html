Sharing files from iPhone to Windows in 2026

Updated July 2026 · 4 min read

Anyone who mixes an iPhone with a Windows laptop knows the pain: AirDrop, iCloud drag-and-drop and Continuity all stop at Apple's fence. Meanwhile you just want that one screenshot on your PC.

The old options

iTunes / Apple Devices app requires a cable and a lot of patience. iCloud for Windows works but needs sign-in on both ends and pushes photos into its own library. Emailing yourself is fine for one file, painful for ten.

The fastest way in 2026: an online clipboard

Open Copy Cloud in Safari on the iPhone. Tap Send, choose the photo or file, and you get a 6-character code plus a QR. On the Windows PC, open Copy Cloud in Edge/Chrome, tap Retrieve, and type the code. The file downloads instantly.

Why this beats cloud drives here

  • No sign-in on either device.
  • Nothing installed - runs in the browser.
  • Clip auto-deletes after 24 hours, so nothing lingers.
  • Works from any Wi-Fi or mobile network - no LAN required.

Tip: install as a PWA

Add Copy Cloud to your iPhone Home Screen ("Share → Add to Home Screen") to open it like a native app next time. Same on Windows: click the install icon in the browser's address bar.
